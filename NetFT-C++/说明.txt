1.由于网页代码中的.c文件中 <arpa/inet.h>和<netdb.h>等头文件 是 POSIX 系统（如 Linux 和 macOS）中的标准头文件。
如果您在 Windows 系统上编译这段代码，可能会遇到问题。为了在 Windows 上兼容，您需要使用一些跨平台库，如 winsock2.h等。
因此需要将一些头文件写成以下形式:
#ifdef _WIN32
#include <winsock2.h>
#include <ws2tcpip.h>
#pragma comment(lib, "Ws2_32.lib")
#else
#include <arpa/inet.h>
#include <sys/types.h>
#include <sys/socket.h>
#include <netdb.h>
#include <unistd.h>
#endif

2.在使用网页版的代码时，可能会遇到"cpp文件中显示全局范围没有close"，"显示std没有成员runtime_error和未定义标识符close"，
“显示byte*类型的实参与const char*类型的形参不相容”等问题，主要是因为没有添加一些头文件，将相应头文件添加进去即可，
可以直接在CSDN搜索相关问题或者使用gpt解决。

3.文件夹里面main.cpp和ATI_connect.cpp函数只需要根据情况选择其中一个使用即可：
（1）当你没有现有项目时，而是新建一个项目时，可以直接用main.cpp函数来获取传感器的数据；
（2）当你已经有一个项目的时候，想要把ATI集成到现有项目中时，可以在主cpp文件中使用ATI_connect.cpp里面的ATI_connect函数。
